# Review rules: polarity-ecosystem/Libraries

npm workspaces of standalone React effect libraries (`packages/border-beam`,
`packages/liquid-gooey`, `packages/thinking-orbs`), each published separately, with demo sites
in `sites/`. Source: `README.md` unless stated. Flag a diff that breaks any of these.

- A change to a package's exports (`src/index.ts`, the `exports` map) or props is a semver event:
  the package version bumps to match, with a `CHANGELOG.md` entry where the package keeps one.
- In `border-beam` and `thinking-orbs`, `spec/` is generated by `npm run spec` and keeps the
  native ports in `ports/` in step with the web renderer. Flag a hand edit to `spec/` or `dist/`,
  and a visual parameter change to the web renderer that does not regenerate the spec.
- `.github/workflows/publish.yml` gives each package its own npm token. Flag a change that lets one
  token publish another package.
- Only `sites/beam` has a `public/CNAME` (GitHub Pages); the other sites deploy through Cloudflare
  Pages and must not add one.
- The demo sites import the library from source, not from npm or `dist/`.
- The workspace root `package-lock.json` is the only lockfile. Flag a new per-package or per-site
  lockfile.
- Flag new files under `packages/thinking-orbs/ports/ios/PillsDemo/build-rel/`: that is Xcode build
  output.
